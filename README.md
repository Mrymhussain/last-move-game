# Last Move

## Game Description

>Last Move is a simple grid game. The player needs to reach the end before the number of moves runs out. Some spaces are blocked, so the player needs to choose the right path.

## User Stories

* As a user, I want to see the game instructions so I know how to play.
* As a user, I want to see how many moves I have left.
* As a user , I want to use direction buttons to move around the grid.
* As a user, I want to reach the safe zone before my moves run out.
* As a user , I want to see a message when I `win` or `lose`. 
* As a user, I want to restart the game and try again.

## Technologies Used
